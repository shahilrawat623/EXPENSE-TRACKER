# Expense Tracker 💰
--
A lightweight web application built with **HTML, CSS, and JavaScript** to track daily expenses and income.   This project helps beginners practice **DOM manipulation, event handling, and localStorage** while building something practical.

---

## 🚀 Features
- Add transactions with description and amount
- Separate totals for **Income** and **Expenses**
- Display overall **Balance**
- Delete transactions
- Data persistence using **localStorage** (no refresh loss)

---

## 🛠️ Tech Stack
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6)** for logic and interactivity
- **localStorage** for saving data

---

## 📸 Demo
1. Enter a description and amount (positive = income, negative = expense).
2. Click **Add Transaction**.
3. See the transaction appear in the list with updated totals.
4. Delete transactions when needed.
5. Refresh the page — data stays saved!
